Buxara Best self-hosted web fonts

Buxara Sans is an axis-limited derivative of Manrope.
Buxara Editorial is an axis-limited derivative of Source Serif 4 by Adobe.
Original copyright and SIL Open Font License notices are included alongside
the font files and remain embedded in their metadata. No glyphs were removed.

Only weights 400 through 700 are delivered. Source Serif's optical-size axis
is pinned at its original default of 20 to reduce transfer and decoding cost.
Latin, Latin extended and Cyrillic subsets retain the original unicode ranges.
The derivative family names distinguish these optimized files from upstream.

The checked-in WOFF2 files are ready to serve: no Python or font compiler is
required by npm ci, the backend, or the Vercel build. For offline maintenance,
install fonttools[woff] and run python scripts/optimize-fonts.py from the root.
FontTools instancing reference:
https://fonttools.readthedocs.io/en/latest/varLib/instancer.html

Upstream sources:
